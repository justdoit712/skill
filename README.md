# Skills 导航目录

公开的 AI Agent Skills 导航：只收录技能的名称、原始链接、中文简述、分类与评估依据。
点进去是上游原仓库，是否使用由你自己判断。

**不下载、不镜像、不安装、不启用、不执行任何技能包。**

计划浏览地址：<https://justdoit712.github.io/skill/>

## 在本地运行

在 PyCharm 中选择项目的 `.venv` 解释器，打开 [run_local.py](tools/run_local.py)，右键 **Run**。
已提供共享运行配置 `Local Skills - 50 recommended`。启动前可先执行：

```powershell
.\.venv\Scripts\python.exe tools/run_local.py --check
```

默认目标是**本次新增 50 个推荐技能**，允许评估超过 50 个候选；本次输入＋输出合计上限
**100M（100,000,000）Token**。参数在 [config/local-run.json](config/local-run.json) 修改。
网络错误及临时 HTTP 错误最多重连 **5 次**（首次加重试共 6 次），重连成功后继续。
达到目标、预算用尽、候选用完、重连用尽或最终响应用量缺失时停止；预算不保证能找到 50 个合格结果。
重试中用量未知的请求按输入字节数＋最大输出＋消息余量预留估算预算，与实际返回的 Token 分开显示。
Token 上限在每次请求后检查，最后一次请求可能超出上限。

模型凭据使用 `config/model.local.json` 或环境变量；GitHub 搜索可设置 `GITHUB_TOKEN`。
控制台显示输入、输出和总 Token，`data/local/latest-run.json` 保存最新用量，
`data/local/runs/<运行编号>/report.md` 展示用量与本次推荐链接。
运行后执行 `scripts/preview.ps1` 可浏览分类目录。

## 定向查找特定需求 Skill

针对特定任务（例如："生成高质量 Prompt"、"Postgres 性能优化"、"React Native 跨平台测试"）查找并比较相关 Skill，可以使用独立工具 [find_skill.py](tools/find_skill.py)。结果基于材料评估，不代表功能实测：

```powershell
# 使用配置中的默认需求；配置也未提供时才交互输入
.\.venv\Scripts\python.exe tools/find_skill.py

# 命令行直接指定需求与候选参数
.\.venv\Scripts\python.exe tools/find_skill.py "生成高质量 Prompt" --limit 5 --max-evaluations 20 --max-tokens 200000
```

### 特性与运行边界
- **需求驱动与跨范围检索**：跳过主目录的分类排他限制（如 Prompt 工程在主目录不单独设类，但在定向查找中可自由搜索）。
- **主目录隔离**：不修改 `data/catalog.json`、`data/queue.json`、候选池和周额度账本；当前会写入独立的前端查找报告。
- **证据检查**：评估包含文件位置和原文片段，程序检查引用。当前核验仍有过宽匹配等已知问题，限制与待修行为见 [运行说明](docs/运行说明.md)，不能据此保证没有模型误判。
- **独立报告留存**：每次查找结果输出在 `data/local/find-skills/<时间戳-UUID>/`，包含 `report.md` 和 `report.json`；同时写入 `public/data/find-report.json` 供页面展示，本地运行不会自动发布。

当前仓库查找配置为短名单 5 项、评估上限 80、总 Token 停止阈值 20,000,000；参数优先级和现有计数限制见运行说明。

### 主分类

| 主分类 | 收录内容 |
| --- | --- |
| 编程开发 | 前后端、重构、调试、测试、代码审查 |
| 文档办公 | Word、PDF、Excel、PPT 等 |
| 内容创作 | 文章、图片、视频、音频 |
| 产品与设计 | 需求分析、界面设计、原型 |
| 自动化 | 浏览器操作、文件处理、工具集成、工作流 |
| 云服务与运维 | 部署、CI/CD、基础设施 |
| 安全 | 漏洞检测、代码安全、审计 |
| 金融与投资 | 宏观、股票、期货、大宗商品及研究和策略辅助 |
| 心理健康 | 情绪记录、压力管理、心理健康信息理解 |
| 身体健康 | 睡眠、运动、饮食及身体健康信息理解 |

科研、通用数据分析、AI 开发不作为独立收录方向；直接服务上述用途的技能仍可纳入，
例如股票数据分析归入金融。

### 不收录

- DSH 插件
- 实盘自动下单类技能
- 面向专业临床诊断与治疗决策的技能

## 条目包含什么

技能名称、原始链接、作者或团队；一至两句中文简述；主分类与标签；上游声明的适用平台、
特殊工具与依赖；来源类型与发现渠道；候选或推荐状态及评估理由；首次发现与最近检查时间；
上游移除或暂时不可访问的状态。

**不编造用途、平台兼容性和变更时间。最近检查时间不代表技能更新时间。**
上游没有声明的兼容性不会被推测。

## 评估方式

六项检查，每项为 `pass` / `fail` / `unknown`，并附证据链接或文件位置：

| 检查 | 说明 |
| --- | --- |
| 范围匹配 | 是否属于收录领域 |
| 用途明确 | 任务与典型场景是否说清 |
| 说明完整 | 步骤、依赖或示例是否足以理解用途 |
| 证据可追溯 | 介绍与实际内容是否相符 |
| 依赖透明 | 特殊工具、运行环境与依赖是否明确 |
| 风险复核 | 是否有可疑行为或与收录范围冲突的功能 |

六项全部通过进入**推荐区**；存在 `unknown` 或说明不完整的留在**候选区**并注明原因。
用户可通过 `config/overrides.json` 将特定技能收入**收藏区**。页面默认展示推荐区，推荐区、候选区与收藏区严格互斥。

已推荐技能的内容发生变化后，会**保留推荐状态并醒目标记"内容已变化，待复核"**，
同时展示原评估对应的版本；复核不通过则降级至候选区。人工收藏条目的内容变化只做中性提示，不自动重评、不自动降级。

## 局限

- 条目**未经实测**，被收录不等于功能可用或安全。
- AI 辅助评估**不等于功能测试或安全审计**。
- 平台兼容性以上游声明为准，本目录不做推测。
- 金融与健康类条目会记录信息来源与主要限制，**不构成投资建议或医疗建议**，
  被收录也不代表专业认证。
- 条目的中文简述、分类与评估是本站衍生内容；各技能仍适用其原始许可。

## 运行方式

计划每周通过 GitHub Actions 自动采集与评估，也支持手动触发。每周新增与重评合计
**最多 50 个**，优先复核发生变化的已有推荐。

Actions 定时与手动共享同一额度账本，手动触发不绕过上限。本地 `run_local.py` 按上述单次目标与预算运行，使用独立账本。网络失败时保留上次有效数据，
不做批量删除或虚假下架。超出本周额度的候选留在跨轮累积的待办队列里，
后续运行按公平轮转依次处理，不会每轮重复跳过同一批。

操作步骤与运行后检查见 [运行说明](docs/运行说明.md)。
