# Skills 导航目录

公开的 AI Agent Skills 导航：只收录技能的名称、原始链接、中文简述、分类与评估依据。
点进去是上游原仓库，是否使用由你自己判断。

**不下载、不镜像、不安装、不启用、不执行任何技能包。**

本项目为本地个人知识库与 Skill 评估系统，产物为静态页面与数据。本地运行与预览请参见 [本地预览与访问](#本地预览与访问)。

## 本地预览与访问

页面是纯静态产物（`public/` 下的 `index.html`、`styles.css`、`js/`、`data/`），本地一键预览：


## 在本地运行

在 PyCharm 中选择项目的 `.venv` 解释器，打开 [run_local.py](tools/run_local.py)，右键 **Run**。
已提供共享运行配置 `Local Skills - 50 recommended`。启动前可先执行：

```powershell
.\.venv\Scripts\python.exe tools/run_local.py --check
```

默认目标是**本次新增 50 个推荐技能**，允许评估超过 50 个候选；本次输入＋输出合计上限
**100M（100,000,000）Token**。参数在 [config/local-run.json](config/runners/local-run.json) 修改。
本地收集默认使用固定 **2 个评估线程**，同时处理两个不同候选；每个候选只进行一轮模型评估。
账本及结果写入串行处理，派发时计入在途请求的估算成本，临近预算或推荐目标时等待已有结果。
停止后不再派发新候选，已发出的请求等待返回并保存；因此按 Ctrl+C 后可能需要等待接口超时。
如需回退单线程，可在上述配置中设置 `"parallel_evaluation": false`；不提供更高并发数配置。
网络错误及临时 HTTP 错误最多重连 **5 次**（首次加重试共 6 次），重连成功后继续。
达到目标、预算用尽、候选用完、重连用尽或最终响应用量缺失时停止；预算不保证能找到 50 个合格结果。
重试中用量未知的请求按输入字节数＋最大输出＋消息余量预留估算预算，与实际返回的 Token 分开显示。
Token 上限在每次请求后检查；预留使用估算值，最后的在途请求仍可能导致超出上限。

模型凭据使用 `config/models/model.local.json` 或环境变量；GitHub 搜索可设置 `GITHUB_TOKEN`。
控制台显示输入、输出和总 Token，`data/local/latest-run.json` 保存最新用量，
`data/local/runs/<运行编号>/report.md` 展示用量与本次推荐链接。
运行后执行 `scripts/preview.ps1` 可浏览分类目录。

## 定向查找特定需求 Skill

针对特定任务（例如："生成高质量 Prompt"、"Postgres 性能优化"、"React Native 跨平台测试"）查找并比较相关 Skill，可以使用独立工具 [find_skill.py](tools/find_skill.py)。结果基于材料评估，不代表功能实测：

```powershell
# 使用配置中的默认需求；配置也未提供时才交互输入
.\.venv\Scripts\python.exe tools/find_skill.py

# 命令行直接指定需求与候选参数
.\.venv\Scripts\python.exe tools/find_skill.py "生成高质量 Prompt" --limit 5 --max-evaluations 20 --max-tokens 200000
```

### 特性与运行边界
- **需求驱动与跨范围检索**：跳过主目录的分类排他限制（如 Prompt 工程在主目录不单独设类，但在定向查找中可自由搜索）。
- **主目录隔离**：不修改 `data/catalog.json`、`data/queue.json`、候选池和周额度账本；当前会写入独立的前端查找报告。
- **证据检查**：评估包含文件位置和原文片段，程序检查引用。当前核验仍有过宽匹配等已知问题，限制与待修行为见 [运行说明](docs/运行说明.md)，不能据此保证没有模型误判。
- **独立报告留存**：每次查找结果输出在 `data/local/find-skills/<时间戳-UUID>/`，包含 `report.md` 和 `report.json`；同时写入 `public/data/find-report.json` 供页面展示，本地运行不会自动发布。

当前仓库查找配置为短名单 5 项、评估上限 80、总 Token 停止阈值 20,000,000；参数优先级和现有计数限制见运行说明。

## 收录范围

### 主分类

| 主分类 | 收录内容 |
| --- | --- |
| 编程开发 | 前后端、重构、调试、测试、代码审查 |
| 文档办公 | Word、PDF、Excel、PPT 等 |
| 内容创作 | 文章、图片、视频、音频 |
| 产品与设计 | 需求分析、界面设计、原型 |
| 自动化 | 浏览器操作、文件处理、工具集成、工作流 |
| 云服务与运维 | 部署、CI/CD、基础设施 |
| 安全 | 漏洞检测、代码安全、审计 |
| 金融与投资 | 宏观、股票、期货、大宗商品及研究和策略辅助 |
| 心理健康 | 情绪记录、压力管理、心理健康信息理解 |
| 身体健康 | 睡眠、运动、饮食及身体健康信息理解 |

科研、通用数据分析、AI 开发不作为独立收录方向；直接服务上述用途的技能仍可纳入，
例如股票数据分析归入金融。

### 不收录

- DSH 插件
- 实盘自动下单类技能
- 面向专业临床诊断与治疗决策的技能

## 条目包含什么

技能名称、原始链接、作者或团队；一至两句中文简述；主分类与标签；上游声明的适用平台、
特殊工具与依赖；来源类型与发现渠道；候选或推荐状态及评估理由；首次发现与最近检查时间；
上游移除或暂时不可访问的状态。

**不编造用途、平台兼容性和变更时间。最近检查时间不代表技能更新时间。**
上游没有声明的兼容性不会被推测。

## 评估方式

六项检查，每项为 `pass` / `fail` / `unknown`，附简短理由；核心功能引用集中核验：

| 检查 | 说明 |
| --- | --- |
| 范围匹配 | 是否属于收录领域 |
| 用途与价值 | 具体问题、适用场景，以及方法、模板或规则的实质价值 |
| 说明与做法 | 材料是否足以理解做法与价值，按技能形态判断 |
| 证据可追溯 | 介绍与实际内容是否相符 |
| 依赖与适用条件 | 已知依赖与信息缺口；仅关键缺口影响推荐 |
| 风险复核 | 是否有可疑行为或与收录范围冲突的功能 |

普通查找采用**导航价值筛选（规则 1.3.0）**：判断材料是否支持“值得进一步了解”。实际价值并入用途判断，可操作性并入说明判断；不再设置额外三项质量门槛。验收清单、示例和验证方法仅作为优点或限制展示，缺少这些不会单独阻止推荐。只有宣传或空泛角色设定、缺少核心材料的技能仍留在候选区。

每项检查给简短理由，核心功能引用集中在“内容依据”，由程序核对完整行与行号；不要求为“未见明显风险”重复举证。依赖信息缺口明确不影响判断时只展示提示，关键运行条件不明仍留候选；材料未声明依赖不等于无依赖或全平台兼容。金融、健康的适用专项检查与原有硬性排除项保留。

每个候选通常调用一次（不含重试）。请求计入原有 Token 总预算；达到预算或用量缺失时保存已完成的评估并停止后续请求。卡片中的“筛选依据”展示检查理由。旧条目保留原评估记录；已完成的本地候选池条目不会因规则升级自动重评。完整说明见 [运行说明](docs/运行说明.md)。
用户可通过 `config/governance/overrides.json` 将特定技能收入**收藏区**，通过 `config/governance/snoozed.json` 设置 150 天冷冻（暂不关注），或通过 `config/governance/owned-skills.json` 标记为**已收录**（从目录与定向查找中隐藏，流水线 0 Token 跳过）。页面默认展示推荐区，各分区严格互斥。

已推荐技能的内容发生变化后，会**保留推荐状态并醒目标记"内容已变化，待复核"**，
同时展示原评估对应的版本；复核不通过则降级至候选区。人工收藏条目的内容变化只做中性提示，不自动重评、不自动降级。

## 局限

- 条目**未经实测**，被收录不等于功能可用或安全。
- AI 辅助评估**不等于功能测试或安全审计**。
- 平台兼容性以上游声明为准，本目录不做推测。
- 金融与健康类条目会记录信息来源与主要限制，**不构成投资建议或医疗建议**，
  被收录也不代表专业认证。
- 条目的中文简述、分类与评估是本站衍生内容；各技能仍适用其原始许可。

## 运行方式

系统统一在本地 Windows PowerShell 环境下运行，通过 `tools/run_local.py` 驱动。本地收集按单次目标与预算运行，支持断点保存、增量累积与离线恢复。网络失败时保留上次有效数据，不做批量删除或虚假下架。超出单次预算或目标的候选保留在候选池与队列中，后续运行依次处理。

操作步骤与运行后检查见 [运行说明](docs/运行说明.md)。

## 贡献

本仓库是一个**公开的 Skills 导航目录**：只收录技能的名称、原始链接、中文简述、分类与评估依据，**不下载、不镜像、不安装、不执行任何技能包**（见 [产品规范](docs/产品规范.md) §1）。因此投稿的是**链接与说明**，不是技能包本身。

### 投稿一个技能

通过 [提交 Issue](https://github.com/justdoit712/skill/issues/new?template=submit-skill.yml) 投稿。

| 字段 | 说明 |
|---|---|
| 技能名称 | 上游使用的名称 |
| SKILL.md 或技能目录链接 | 指向上游仓库中的**具体文件或目录**，不是仓库首页 |
| 原始作者或仓库 | 上游出处 |
| 来源类型 | 官方（待核实）／社区 |
| 用途 | 做什么、典型使用场景 |
| 主分类 | 见上方[收录范围](#收录范围)（十个主分类中选一个） |
| 依据链接或文件位置 | 支持上述用途判断的证据 |
| 依赖说明 | 上游**明确声明**的特殊工具、运行环境与依赖；未说明的不要推测 |
| 许可 | 能确认就填，无法确认写"未知" |
| 能力披露 | 涉及金融、健康或交易执行能力时必填 |

投稿只创建一条**待检查记录**，不直接进入推荐区，也不代表任何官方身份或专业认证。

### 纠错

条目信息有误、链接失效、上游已变更，或你希望自己的技能从目录中移除，请提 Issue 说明。
