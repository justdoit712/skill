# 百炼模型池黑名单（不兼容模型过滤清单）

本文档记录阿里云百炼平台（Bailian）中**因固有缺陷、垂直专用或接口不兼容必须过滤排除的模型**。
后续导入新免费额度模型时，可依据此表与过滤规则直接剔除。

---

## 一、 需过滤排除的模型清单（共 47 个）

### 1. 多模态视觉 / OCR / GUI 模型（17 个）
> **排除原因**：多模态/图像/OCR专用，不兼容纯文本 JSON 结构化评估契约，易输出未闭合 JSON 字符串或截断。
- `qwen-vl-ocr-2025-11-20`
- `qwen-vl-ocr-latest`
- `qwen-vl-plus`
- `qwen3-vl-32b-instruct`
- `qwen-vl-ocr-1028`
- `qwen3-vl-235b-a22b-instruct`
- `gui-plus`
- `gui-plus-2026-02-26`
- `qvq-max`
- `qvq-plus`
- `qwen3-vl-plus`
- `qwen3-vl-flash`
- `qwen3-vl-8b-instruct`
- `qwen-vl-ocr-2025-08-28`
- `qwen-vl-ocr-2025-04-13`
- `qwen-vl-ocr`
- `qwen3.5-ocr`

### 2. 垂直领域专用模型（15 个）
> **排除原因**：数学、翻译、意图识别、角色扮演或垂直分析模型，无通用技能理解与 JSON 评估能力。
- **数学专用 (5个)**：`qwen-math-turbo`, `qwen-math-plus`, `qwen-math-plus-0816`, `qwen-math-plus-0919`, `qwen-math-plus-latest`
- **翻译专用 (4个)**：`qwen-mt-flash`, `qwen-mt-lite`, `qwen-mt-plus`, `qwen-mt-turbo`
- **意图识别 (1个)**：`tongyi-intent-detect-v3`
- **角色扮演 (3个)**：`qwen-flash-character-2026-02-26`, `qwen-plus-character`, `qwen-flash-character`
- **垂直分析 (2个)**：`tongyi-xiaomi-analysis-pro`, `tongyi-xiaomi-analysis-flash`

### 3. 蒸馏与深度思考空响应模型（5 个）
> **排除原因**：频繁返回空正文（Empty Response），触发有限重试后导致系统进入长时间冷却。
- `deepseek-r1-distill-qwen-7b`
- `deepseek-r1-distill-qwen-14b`
- `deepseek-r1-distill-qwen-32b`
- `kimi-k2-thinking`
- `qwen3-next-80b-a3b-thinking`

### 4. 强制流式 (Stream) 模型（3 个）
> **排除原因**：百炼接口不支持非流式单次调用，直接报错 HTTP 400 `invalid_parameter_error: stream`。
- `qwq-plus`
- `glm-4.5`
- `glm-4.5-air`

### 5. 接口参数不兼容模型（4 个）
> **排除原因**：OpenAI 兼容接口报 HTTP 400 `enable_thinking` 参数不兼容。
- `qwen3-8b`
- `qwen3-14b`
- `qwen3-30b-a3b`
- `qwen3-32b`

### 6. 输出结构校验未通过模型（1 个）
> **排除原因**：输出内容缺失 `main_category` 必填分类字段，无法通过业务契约校验。
- `qwen3-coder-next`

### 7. Instruct 指令格式缺陷模型（1 个）
> **排除原因**：输出 JSON 频繁夹杂未转义非法控制字符（`Invalid control character`）或字符串未闭合截断，无法正常反序列化。
- `Moonshot-Kimi-K2-Instruct`

### 8. 严重超时模型（1 个）
> **排除原因**：超大参数 MoE 模型在百炼端频繁出现 `ReadTimeout` 读取超时（120秒无响应）。
- `qwen3-235b-a22b`
