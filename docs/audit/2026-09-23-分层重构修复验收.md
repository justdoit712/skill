## 离线恢复命令

从已完成评估记录恢复目录及页面，无需模型凭据：

```powershell
.\.venv\Scripts\python.exe tools/run_local.py --recover-catalog
```

从已有运行的 report.json 重建 Markdown；可选同步本地 public/data 快照：

```powershell
.\.venv\Scripts\python.exe tools/find_skill.py --rebuild-report "data/local/find-skills/<运行目录>"
.\.venv\Scripts\python.exe tools/find_skill.py --rebuild-report "data/local/find-skills/<运行目录>" --publish-snapshot
```

请用实际运行目录替换占位符。恢复不会重新发送 unknown/started 模型请求。新完成记录自带候选与预筛事实；旧记录缺少这些事实且原队列也不存在时，会返回跳过诊断，不能凭空恢复。硬中止遗留的锁不会被自动抢占；确认没有活动写者后才可清理对应锁。
