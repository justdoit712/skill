## 四、下一步：逐步确定人物过滤尺度

用户明确要求一步一步执行。下一次接续应从三天内的过滤判断开始，不直接批量过滤全部记录，不跳到笔记总结。

### 1. 先看少量实际例子

在已确定的三天范围内，呈现少量有代表性的原始问答或交叉讨论，针对群友消息说明：

- 建议保留或删除哪一条。
- 它与哪条大师发言有关。
- 删掉后是否会造成提问缺失、指代不明或条件丢失。

优先展示确实存在判断分歧的例子，例如直接提问、群友补充、简单回应和独立闲聊。不要用大篇分析替代原话与具体判断。

### 2. 用反馈确定规则，再做过滤试跑

目前的讨论起点是：保留大师全部发言，群友消息优先保留理解大师发言所必需的上下文。具体边界仍要通过例子和用户反馈确认，不能把先前 AI 的所有建议都当作已定规则。

根据用户对例子的反馈，在约定的小范围内试跑，记录实际采用的判断和遇到的问题。用户试读后，再逐步处理剩余记录。

### 3. 过滤结果如何检查

- 大师原有发言完整保留，正文与附件不被改写。
- 留下的短答、引用和问答能够理解。
- 群友消息的保留有具体理由。
- HTML 的计数、搜索和跳转与实际保留内容一致。
- JSON 仍是完整的只读上下文来源。

这些检查用于验证试跑结果，不意味着现在已经完成全量语义分析。
